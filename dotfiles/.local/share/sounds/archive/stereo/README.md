# Archive sound theme

Record these yourself (phone, quiet room) and run each through
`archive-sound-prep recording.wav EVENT`. Missing files are simply silent.

| File | Event (`archive-sound-prep` name) | What to record | Length |
| --- | --- | --- | --- |
| `desktop-login.oga` | `login` | a wooden card-catalogue drawer sliding open | ~600 ms |
| `desktop-logout.oga` | `lock` | the same drawer sliding shut | ~500 ms |
| `message-new-instant.oga` | `message` | one soft rubber-stamp press | ~150 ms |
| `dialog-warning.oga` | `urgent` | two firm stamp presses | ~350 ms |
| `screen-capture.oga` | `capture` | a vintage camera shutter | ~250 ms |
| `audio-volume-change.oga` | `volume` | a single pencil tick on paper | ~40 ms |
| `power-plug.oga` | `plug` | a paper clip snapping onto a card | ~120 ms |
| `battery-low.oga` | `battery` | a small brass desk bell, struck lightly once | ~800 ms |
| `dialog-error.oga` | `error` | two quick knuckle taps on a wooden desk | ~200 ms |
| `bell.oga` | `bell` | a typewriter's carriage bell (the label typewriter's Return) | ~400 ms |

CC0 sounds from freesound.org work as a fallback (filter by the CC0 licence).
Silent on purpose: typing, focus changes, opening and closing windows,
switching workspaces, hovering.
